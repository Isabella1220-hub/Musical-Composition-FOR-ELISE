# Für Elise in TunePad

## 1. Project Overview

This project is a recreation of Beethoven's *Für Elise* using TunePad, a music coding platform. I used Python-style code to create different musical parts, including the right-hand piano melody, left-hand piano accompaniment, and background harmony. The music is written in A minor, with a tempo of 70 BPM and a time signature of 3/8. I used coding functions such as `playNote()` and `rest()`, as well as lists and beat durations, to control the notes, rhythm, and timing of the music.

## 2. How to Run

To listen to my project, follow these steps:

1. Open the [TunePad website](https://tunepad.com) and access my project using the link below.
2. Make sure all three tracks (Right Hand, Left Hand, and Background Pad) are enabled.
3. Reset the playback to the beginning of the music.
4. Click the **Play** button to listen to the complete composition.
5. You can also use the mute or solo buttons to listen to each musical part separately.

**TunePad Project Link:** [Für Elise](https://github.com/Isabella1220-hub/Musical-Composition-FOR-ELISE/blob/main/README.md)]

The three tracks have different roles:

- **Right Hand:** Plays the main melody of *Für Elise*.
- **Left Hand:** Provides the piano accompaniment.
- **Background Pad:** Adds background harmony to make the music sound fuller.
